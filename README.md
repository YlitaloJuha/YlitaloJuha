### Claude Code mods

<img src="images/claude-mods.png" width="720" alt="The context and limit bars from claude-bars above the row of shortcuts from claude-dev-shortcuts, in the Claude desktop app">

<sub>A quick peek in the desktop app: `claude-bars` on top, `claude-dev-shortcuts` below.</sub>

Small add-ons for Claude Code. Each one works alone, and they work side by side:

| Mod | What it does |
|---|---|
| [claude-bars](https://github.com/YlitaloJuha/claude-bars) | Context and plan limits as one quiet line, with every subagent and background task and how long each has run. |
| [claude-afk](https://github.com/YlitaloJuha/claude-afk) | Walk away and leave Claude working: develop, test, refactor or housekeeping, under rules you can read. |
| [claude-wrap-up](https://github.com/YlitaloJuha/claude-wrap-up) | One button to finish a session properly: stop, verify, update the docs, leave a handoff, then ask before you commit. |
| [claude-todos](https://github.com/YlitaloJuha/claude-todos) | Say "todo" the way you already do. It gets saved, stays on screen, and is there when you ask. |
| [claude-ambiguous](https://github.com/YlitaloJuha/claude-ambiguous) | Catches the prompt Claude could take two ways, while you can still say which you meant. |
| [claude-lazy-reply](https://github.com/YlitaloJuha/claude-lazy-reply) | Answer Claude with one tap: a fast model offers the replies you were about to type. |
| [claude-comeback-cost](https://github.com/YlitaloJuha/claude-comeback-cost) | See what your next message will cost before you send it, when the prompt cache has gone cold. |
| [claude-dev-shortcuts](https://github.com/YlitaloJuha/claude-dev-shortcuts) | A row of shortcuts above the prompt: challenge the plan, serve it to a new session, walk away, wrap up, and thin out your memory once it has grown. Already contains claude-afk and claude-wrap-up, so use it instead of those two. |
